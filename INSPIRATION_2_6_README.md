# ZYLO Inspiration & Design Discovery 2.6

## Adds
- `/inspiration` user-facing discovery page.
- Filters by space type and target style.
- Practical palettes, improvement directions and approximate refresh ranges.
- Covers all 12 ZYLO space types across a starter set of ideas.
- “Use this direction” routes users into My Homes so inspiration connects to the existing actual-room workflow.
- Uses existing ZYLO UI classes; no new package or database migration.

## Preserved
- Homepage and its existing Explore Ideas link.
- Whole-House 2.4.
- Visual AI 2.5.
- Supabase auth/storage/history.
- Existing backend and Stability AI behavior.

This milestone intentionally avoids paid generation and external image licensing complexity. A later version can add curated/licensed visual reference images and one-click prefill into a selected space.
