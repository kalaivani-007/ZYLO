# ZYLO Smart Budget Planner 2.7

## Adds
- Live budget allocation inside the existing space workspace.
- Recalculates immediately when the user changes the ₹ budget.
- Allocation changes with redesign intensity:
  - Light Refresh favors reuse, lighting and decor.
  - Balanced Redesign uses a balanced whole-room split.
  - Major Makeover increases materials/finish allocation.
- Five transparent categories:
  - Furniture
  - Materials & finishes
  - Lighting
  - Decor
  - Contingency buffer
- Budget tier label.
- Space-aware spend-first guidance.
- Keep-list reuse reminder and requested-change priority.

## Important
The planner is an indicative planning allocation, not a live product-price,
contractor quote or guarantee.

## Preserved
Visual AI 2.5, Inspiration 2.6, design-plan API, Stability generation,
Supabase save/history, image optimization and the lazy 3D prototype.

No database migration, backend change or new dependency is required.
